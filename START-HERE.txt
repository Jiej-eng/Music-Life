AURELIA VINYL LIVE — START HERE

1. Install Node.js 20+.
2. Extract this ZIP.
3. Open a terminal in the extracted aurelia-vinyl-live folder.
4. Run: npm install
5. Run: npm run dev
6. Open: http://localhost:5173
